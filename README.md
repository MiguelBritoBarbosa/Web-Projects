# PAW - Exercícios de Programação Web 🐘

Este repositório contém exercícios de programação web desenvolvidos em diversas linguagens, incluindo HTML5, CSS3, PHP e JavaScript. O objetivo é fornecer um registro de evolução e um local para armazenar e compartilhar os exercícios realizados.

**Estrutura do Repositório**

O repositório é dividido em pastas, cada uma contendo exercícios relacionados a uma linguagem ou tecnologia específica.

* `Lista de Exercício`: contém exercícios de programação web em geral
* `Projeto_PAW_3°Bimestre`: contém projetos desenvolvidos durante o 3° bimestre
* `ProjetoBD`: contém projetos relacionados a banco de dados
* `README.md`: este arquivo de leitura

**Tecnologias Utilizadas**

* HTML5
* CSS3
* PHP
* JavaScript
* Bootstrap

**Como Contribuir**

Se você deseja contribuir com este repositório, por favor, siga as seguintes etapas:

1. Faça um fork do repositório
2. Crie uma nova branch para sua contribuição
3. Adicione seus exercícios ou projetos à branch
4. Faça um pull request para o repositório original
